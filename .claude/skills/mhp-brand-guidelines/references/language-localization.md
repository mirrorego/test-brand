# MHP Brand Design System — Language & Localization

Reference file for generating on-brand code, layouts, and assets. Rules below are constraints, not suggestions — treat "Forbidden" as hard blocks in generated output.

---

- **Corporate English:** American English, Chicago Manual of Style
- **Title case:** capitalize nouns, pronouns, verbs, adjectives, adverbs, subordinating conjunctions. Lowercase articles, coordinating conjunctions, and prepositions unless they begin/end the phrase.
- **German:** must comply with Duden rules. Gender-relevant nouns use colon structure (e.g. *Mitarbeiter:innen*) for full inclusivity.
